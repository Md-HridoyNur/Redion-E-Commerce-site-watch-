# ⌚ Redion| Premium Watch E-Commerce

A sophisticated, responsive e-commerce landing page designed for a high-end watch boutique. This project showcases a seamless blend of luxury aesthetics and functional frontend logic.

---

## ✨ Features

* **Dynamic Product Grid:** Inventory is managed via a JavaScript array and injected into the DOM automatically.
* **Smart Call-to-Action:** The UI detects if a product has a price; if so, it displays "Add to Cart." If the price is missing (e.g., for exclusive sets), it displays "View More".
* **Interactive Cart:** Real-time cart counter updates in the navigation bar using state management.
* **Luxury Design:** * **Typography:** Utilizes *Playfair Display* for headings and *Great Vibes* for the branding.
    * **Visual Feedback:** Smooth hover effects and CSS transformations on product cards.
    * **Gold Accents:** Consistent use of a signature gold color (`#d4af37`) for primary buttons and links.
* **Fully Responsive:** Built with CSS Grid and Flexbox to ensure a premium experience across mobile, tablet, and desktop.

---

## 🛠️ Technology Stack

* **HTML5:** Semantic markup for SEO and accessibility.
* **CSS3:** Custom styles including a sticky navbar and hero overlays.
* **JavaScript (ES6):** Logic for product rendering, currency formatting, and cart functionality.
* **Google Fonts:** Integrated luxury typography.
